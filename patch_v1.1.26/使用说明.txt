赛尔号 精灵美术修复累积补丁（v1.1.26）
======================================

本补丁是「累积补丁」：已包含 v1.1.16 / v1.1.15 的全部文件，
再叠加 3041 的真实逐帧战斗动画、对战立绘放大与待机节奏修正。
已装 v1.1.11 及以后版本的用户，只装这一个包。

【v1.1.26 新增：战斗立绘 1.25 倍 + 待机卡顿修复】
1) 战斗立绘再放大 1.25 倍
   实测待机图并没有走 trim：playerPet 节点上只有 Image / Animator / Outline，
   显示尺寸由 prefab 的 RectTransform 330x389 固定，trim 不参与。
   本版直接修改 fight 包中 playerPet 的 sizeDelta：
       330 x 389  ->  412.5 x 486.25   （1.25 倍）
   底边 pivot(0.5, 0) 不变，脚底位置不动，只向上长大。
   注意：playerPet 是玩家侧精灵共用的显示框，
   因此所有玩家侧精灵的战斗形象都会同步放大 1.25 倍。

2) 待机“卡顿 / 不连续”修复
   官方 SWF 第 9~30 帧共 22 帧，实际只有 7 个不同姿势（A 出现 3 次）：
       A=9~11 / 16~18 / 23~24, B=12~13, C=14~15, D=19~20,
       E=21~22, F=25~26 / 29~30, G=27~28
   v1.1.25 用 22 帧等距取样到 21 个关键帧，把 E 姿势压成 1 帧（40ms），
   播放时会出现一次很短的“闪帧”，看起来卡顿。
   本版按官方姿势序列重排为：
       A3, B2, C2, A2, D2, E2, A2, F2, G2, F2
   每个姿势稳定停留 80ms，不再有单帧闪跳。

3) 其它
   - 待机画布 469x500 -> 586x625，为放大后的显示尺寸保留分辨率；
   - 3041_1 仍为 25fps / 0.84 秒循环；
   - 攻击 3041_2/3/4 共 197 帧的贴图、Sprite、trim、clip
     与 v1.1.23 逐字节一致，不受影响。

  21 帧直接取自官方矢量源
  http://seer.61.com/resource/fightResource/pet/swf/3041.swf
  （FFDec 导出 DefineSprite_139_pet 逐帧 SVG，4 倍超采样渲染）。
  SWF 原 30 帧中第 6~8 帧是全屏蓝色爆发特效（会完全遮住本体），
  未采用，待机循环里不会出现爆发闪烁。

【安装】
1. 备份原 APK；
2. 用 MT 管理器 / ZArchiver 打开 APK，把本补丁的 assets 目录按原路径覆盖；
3. 用补丁内 seer-patch.keystore 重新签名：
     别名 seerpatch    密码 SeerPatch2026!
4. 与 v1.1.11+ 本系列签名一致，可直接覆盖安装，存档保留。
