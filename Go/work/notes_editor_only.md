# PlayerData 编辑器 v2.0

独立的 PlayerData 编辑工具，**不改动游戏本体**，安装即用。

## 本次更新

- 支持「修仙模式」等级无上限：游戏内该开关对应客户端 `PetManager.HasUnlimitedLevels`，
  关闭时等级上限 100，开启后为 2147483647。编辑器在「更多功能」新增「修仙模式等级上限」开关，
  开启后精灵背包卡片与仓库修改弹窗的等级范围同步放宽；读取到已有超过 100 级的精灵时会自动开启并提示。

- 修复精灵仓库「修改」弹窗里性格 / 特性 / 性别改完点保存仍提示「没有修改」：
  这三个下拉原先只在整页保存时才回写，弹窗内保存读到的是旧值；现改为选中即同步取值，保存可正确识别改动。

- 特性选择列表改序：「无」保持第一，「超凡」紧跟在「无」之后（第二个），其余特性维持原顺序；
  存档写入值不变（仍是 0=无、i=原特性下标），只调整界面显示顺序。

- 修复「新增精灵」列表里少数精灵没有「物攻 / 特攻」标签：种族值表（petstats）原先只覆盖 1014 个有效精灵中的 1014−39，闪光系列与 10000 段新精灵（如 #10011 哈姆雷斯、#5011 咤克斯、#5605–5608、#10001–10027）完全缺条目，界面查不到数据就不显示标签、也不参与自动培养方案；

- 自动配置同步恢复：这些精灵现在会按特攻 / 物攻种族值正确选择性格（保守 / 固执）与学习力分配，不再一律落到「暂无数据 · 按物攻型处理」；
- 已有 1014 条数据保持不变（其中 3 条与当前 Monster 表略有出入的旧值按原样保留，不影响使用）。

## 已知限制

Android 14 / HyperOS 禁止普通应用直读其它应用的 `Android/data`，
需用 MT/文件管理复制到 Download 编辑后再覆盖回去。

## 存档格式

UTF-8 字节 XOR 16 字节密钥后 Base64；
密钥为 `MD5("YourSuperSecretSalt_2025!")` 的前 16 个十六进制字符。
